# GTA Clip Factory

Abra `iniciar-fabrica.ps1` com o PowerShell para iniciar o painel em `http://127.0.0.1:8765`.

O painel lê os MP4 exportados da fábrica, mostra a fila e mantém o intervalo mínimo de 15 minutos. O envio para TikTok e Instagram continua dependendo das sessões autenticadas abertas no navegador.
